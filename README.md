# НЕСЛУЧАЙНЫЙ КАДР — сайт фотографа Полины Бунтовской

Одностраничный адаптивный сайт на HTML, CSS и JavaScript.

## Запуск

1. Откройте файл `index.html` в браузере двойным кликом.
2. Или запустите локальный сервер (рекомендуется для корректной загрузки):

```bash
npx serve .
```

Либо через расширение Live Server в VS Code / Cursor.

## Структура проекта

```
├── index.html          — главная страница
├── privacy.html        — политика конфиденциальности
├── consent.html        — согласие на обработку данных
├── css/
│   ├── variables.css   — переменные (цвета, шрифты)
│   ├── base.css        — базовые стили
│   ├── sections.css    — секции сайта
│   ├── animations.css  — анимации
│   └── cursor.css      — авторский курсор
├── js/
│   └── main.js         — логика (форма, фильтры, карусель)
├── data/
│   ├── content.js      — тексты, направления, FAQ, контакты
│   ├── portfolio.js    — портфолио и фильтры
│   └── reviews.js      — отзывы
└── images/             — фотографии
```

## Что заменить перед публикацией

### Контакты (`data/content.js`)
- `[ССЫЛКА НА TELEGRAM]` — ссылка на Telegram
- `[ТЕЛЕФОН]` — номер телефона
- `[E-MAIL]` — email

### Фотографии
- `images/hero.png` — портрет для первого экрана
- `images/about.jpg` — фото для блока «О фотографе»
- `images/portfolio-*.jpg` — работы в портфолио
- Замените демо-изображения (Unsplash) в `data/portfolio.js` на реальные
- Обновите AI-блок в `data/content.js` → `aiBlock.images`

### Маркировка изображений (`data/portfolio.js`)
- `mark: null` — реальные работы (без отметки)
- `mark: "visual"` — визуальные примеры
- `mark: "ai"` — AI-концепты

### Отзывы (`data/reviews.js`)
- Замените демонстрационные отзывы на реальные
- Уберите `demo: true` для настоящих отзывов

### Форма (`js/main.js`)
- Подключите реальную отправку (Telegram Bot, email-сервис и т.д.)
- Уберите демонстрационное сообщение в `data/content.js` → `form`

### Юридические страницы
- `privacy.html` и `consent.html` — замените `[E-MAIL]` и актуализируйте текст
